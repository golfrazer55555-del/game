# 철거왕 (Demolition King)

픽셀 블록으로 만든 건물을 **크레인 쇠공, 굴착기, 발파**로 실제처럼 철거하는 시뮬레이션 게임입니다.
PC와 휴대폰에서 모두 동작하고, 가로 화면이 기본이며, 크롬에서 앱처럼 설치할 수 있습니다(PWA).

- 블록 한 칸 = 25 cm. 10층 아파트 하나가 블록 약 13만 개로 되어 있습니다.
- 건물은 층마다 하중과 무게중심을 계산합니다. 기둥을 끊으면 위층이 내려앉고, 한쪽만 끊으면 그쪽으로 넘어갑니다.
- 무너진 덩어리는 물리 엔진으로 떨어지고, 부딪힌 자리부터 부서져 잔해 더미가 쌓입니다.

## 하는 법

| 장비 | 하는 일 |
|---|---|
| 크롤러 크레인 | 선회·붐·윈치를 레버로 조작해 쇠공을 흔들거나 떨어뜨립니다. 과부하(LMI) 100%를 넘기면 안전 위반 |
| 굴착기 | 실제 굴착기처럼 두 레버로 붐·암·버킷을 움직입니다. 압쇄기(물어뜯기), 브레이커(쪼기), 버킷(잔해를 덤프트럭에 싣기) |
| 발파 | 기둥·내력벽에 장약을 넣고 지연 시간(0~3초)을 정해 무너지는 방향을 설계합니다. 끝나면 슬로모션으로 다시 볼 수 있습니다 |

### 조작

| 동작 | PC | 휴대폰 |
|---|---|---|
| 왼쪽 레버 | `W` `A` `S` `D` | 왼쪽 조이스틱 |
| 오른쪽 레버 | 방향키 | 오른쪽 조이스틱 |
| 동작 (자유낙하·물기·타격) | `Space` | 빨간 버튼 |
| 작업 ↔ 주행 | `R` | 주행 버튼 |
| 카메라 / 구조 보기 / 장비 | `C` / `V` / `1` `2` `3` | 오른쪽 위 버튼 |
| 어태치먼트 바꾸기 | `Q` `E` | 오른쪽 목록 |
| 미세 조작 | `Shift` 누른 채로 | 레버를 조금만 |

게임패드도 됩니다 (스틱 2개 = 레버, A/RT = 동작, X = 주행, Y = 카메라, LB/RB = 장비).

### 의뢰 7개

낡은 창고 → 골목 단독주택 → 3층 상가 → 공장 굴뚝 → 5층 사무실 → 급수탑 → 10층 아파트.
의뢰를 끝내면 계약금에서 장비 가동비, 장약값, 이웃 배상금 등을 뺀 돈을 받고, 차고에서 무거운 쇠공·긴 붐·롱붐 굴착기 등을 살 수 있습니다.
**자유 철거**에서는 돈과 시간 걱정 없이 모든 장비로 마음껏 부술 수 있습니다.

## 실행

Node.js 18 이상이 필요합니다.

```bash
cd demolition
npm install
npm start
```

브라우저에서 `http://localhost:8090` 을 엽니다. 같은 와이파이의 휴대폰에서는 터미널에 나오는 주소로 접속합니다.

## 배포본과 크롬 설치

```bash
npm run build      # dist/ 생성 (HTML + JS 번들 + 서비스 워커 + 아이콘)
npm run preview    # http://localhost:8091 에서 배포본 확인
```

크롬 설치(PWA)는 HTTPS 주소에서만 됩니다(내 컴퓨터의 `localhost`는 예외).
이 저장소에는 GitHub Pages 자동 배포가 들어 있습니다.

1. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다 (처음 한 번).
2. `main` 브랜치에 올리면 `.github/workflows/demolition-pages.yml`이 테스트·빌드 후 배포합니다.
3. `https://<아이디>.github.io/<저장소>/` 에 들어가서
   - PC 크롬: 주소창 오른쪽 설치 아이콘, 또는 타이틀 화면의 **앱으로 설치** 버튼
   - 안드로이드 크롬: 메뉴 → **앱 설치** (또는 타이틀의 버튼)
   - 아이폰 사파리: 공유 → **홈 화면에 추가**

설치하면 전체 화면·가로 고정으로 열리고, 한 번 받은 뒤에는 오프라인에서도 실행됩니다.

## 테스트

```bash
npm test
```

메시 생성, 구조 해석(기둥 절단·벽 구멍·전도), 모든 건물이 처음에 스스로 서 있는지, 발파 리플레이가 똑같이 재현되는지, 쇠공·압쇄기가 실제로 블록을 부수는지 확인합니다.

## 폴더 구조

```
index.html            화면 구성과 스타일 (메뉴, HUD, 조이스틱)
manifest.webmanifest  설치형 앱 정보 (가로 고정, 아이콘)
src/
  config.js           블록 크기, 부지 크기, 품질 단계
  materials.js        재질표: 밀도·강도·인성·버틸 수 있는 거리
  world.js            블록 저장, 변경 추적, 레이캐스트
  mesher.js           탐욕 메시 생성 (AO 포함)
  render.js           픽셀 블록 셰이더, 청크·덩어리 메시
  structure.js        구조 해석 (국부 지지 + 층별 하중·편심)
  physics.js          Rapier 물리 연결
  bodies.js           떨어지는 덩어리: 충돌 시 부서짐, 쪼개짐, 멈추면 잔해로
  debris.js           파편과 잔해 더미 (흘러내림)
  damage.js           부수기: 재질별 반경, 파편·먼지·소리 이벤트
  sim.js              고정 시간 간격 시뮬레이션, 스냅샷(리플레이)
  buildings/gen.js    건물 생성기 7종 + 이웃·자동차·가로수
  site.js             현장 배치
  machines/           크레인, 굴착기, 발파, 덤프트럭
  session.js          현장 하나의 진행
  game.js / ui.js     화면 전환, HUD, 저장
  audio.js            효과음 합성 (음원 파일 없음)
  pwa.js              설치 버튼, 서비스 워커, 전체 화면
tools/                개발 서버, 빌드, 아이콘 생성
test/                 Node 테스트
```
