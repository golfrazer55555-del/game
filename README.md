# 포화의 전선 (Line of Fire: 1944)

블록(복셀) 스타일의 2차대전 전차 **1:1 턴제 포격전**입니다. 방위각·고각·장약을 정해 쏘고, 관측 보고를 보며 다음 발을 보정해 적 전차를 격파합니다.

> 현재 버전: **1단계 프로토타입 (v0.1)**. "쏘는 게 재밌나?"를 확인하기 위한 버전입니다.

## 플레이 방법

| 조작 | 휴대폰 | PC |
|---|---|---|
| 포탑 회전 (방위각) | 화면 좌우로 끌기, `−`/`+` 버튼 | `←` `→` (Shift: 0.1° 단위) |
| 포신 각도 (고각) | 화면 위아래로 끌기, `−`/`+` 버튼 | `↑` `↓` |
| 장약 모으기 → 발사 | 발사 버튼 **길게 누르기 → 떼기** | `Space` 누르고 있다가 떼기 |
| 이동 | `이동` → 노란 원 안 지점 터치 | `M` |
| 쌍안경 (적 확대) | `쌍안경` | `B` |

- 빗나가면 **관측 보고**가 나옵니다. 예: "목표보다 38m 멀리, 12m 우측 착탄" → 장약을 조금 줄이고 포탑을 왼쪽으로.
- 직전 사격값이 화면에 남고, 발사 버튼 둘레에 이전 장약 위치가 흰 눈금으로 표시됩니다.
- **바람**은 매 턴 바뀝니다. 위쪽 화살표는 바람이 부는 방향(현재 시점 기준)이고, 공중의 재와 깃발도 바람에 날립니다.
- 크게 **이동하면 적의 조준 보정이 흐트러집니다.** 맞기 시작하면 움직이세요.
- 포탄이 떨어진 곳은 지형이 파괴됩니다. 발밑이 꺼지면 전차가 추락해 피해를 입습니다.

### 난이도

| 난이도 | 궤적 가이드 | 바람 | 적 AI |
|---|---|---|---|
| 훈련병 | 30% | 최대 4m/s | 보정이 느림 |
| 정규군 | 15% | 최대 7m/s | 보통 |
| 베테랑 | 없음 | 최대 10m/s | 2~3발 만에 보정 |

별 3개 조건: 승리 · 6발 이내 격파 · 체력 50 이상 유지

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm start
```

브라우저에서 `http://localhost:8080` 을 엽니다. 같은 와이파이에 연결된 휴대폰에서는 터미널에 표시되는 주소로 접속하면 됩니다.

HTML 한 파일짜리 배포본은 아래 명령으로 만듭니다 (웹 게임 포털 업로드, 앱 포장용).

```bash
npm install
```

```bash
npm run build
```

결과물: `dist/index.html`

## 폴더 구조

```
index.html        화면 레이아웃과 스타일 (HUD, 타이틀, 결과 화면)
js/config.js      밸런스 값 (맵 크기, 중력, 피해량, 난이도별 AI 오차 등)
js/voxel.js       지형 생성 · 메시 생성 · 폭발로 인한 파괴
js/tank.js        블록 전차 모델, 포탑 회전, 이동, 추락, 격파 연출
js/ballistics.js  탄도 계산 (중력 + 바람)
js/ai.js          적 포수 AI
js/game.js        턴 진행, 사격, 피해, 승패
js/effects.js     폭발 · 파편 · 연기 파티클
js/camera.js      카메라 연출
js/ui.js          HUD, 입력, 미니맵
js/audio.js       효과음 (Web Audio로 합성, 음원 파일 없음)
js/lib/           three.js (3D 엔진, MIT 라이선스)
tools/            개발 서버, 빌드 스크립트
```

게임 밸런스는 대부분 `js/config.js` 한 곳에서 조정할 수 있습니다.
